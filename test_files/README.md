# Test data

`test1.mgf` contains two MS3 spectra (Glaucine and Tetramethylkaempferol; titles ending
`|||158` and `|||165,588`) from the MSnLib file
`20250828_targetmol_hts_np_pos_msn.mgf`, unmodified.

- Source: MSnLib mass spectral libraries, Zenodo, doi:10.5281/zenodo.21105617
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Please cite: Brungs C. et al. MSnLib: efficient generation of open
  multi-stage fragmentation mass spectral libraries. Nature Methods (2025),
  doi:10.1038/s41592-025-02813-0

Larger files used by `#[ignore]`d tests and by the examples are not
redistributed here; see "Tests" and "Examples" in the top-level README.
